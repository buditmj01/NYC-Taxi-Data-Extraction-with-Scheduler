🚀 data_pipeline.py (MAIN ETL PIPELINE - OOP ARCHITECTURE)
-----------------------------------------------------------
Purpose: Production-grade PySpark ETL pipeline with OOP design
Input:   Green + Yellow taxi parquet files (September 2025)
Output:  5 CSV aggregation files in output/ directory

Architecture:
- Strategy Pattern: Pluggable aggregation strategies
- Builder Pattern: Fluent API for engine configuration
- Dependency Injection: Configurable pipeline components
- SOLID Principles: Single responsibility, extensibility

15 Classes Implemented:
1. PipelineConfig - Immutable configuration (dataclass)
2. DataLoader - Data ingestion with validation
3. SchemaTransformer (ABC) - Abstract schema transformer
4. GreenTaxiTransformer - Green taxi normalization
5. YellowTaxiTransformer - Yellow taxi normalization
6. DataCleaner - Data validation & cleaning
7. AggregationStrategy (ABC) - Abstract aggregation base
8. TripsPerDayAggregation - Trip count aggregation
9. RevenuePerDayAggregation - Revenue aggregation
10. PeakHourAggregation - Peak hour detection
11. DailyAvgMetricsAggregation - Average metrics
12. AnomalyDetectionAggregation - Anomaly detection
13. AggregationEngine - Strategy orchestrator
14. OutputManager - CSV output handling
15. NYCTaxiPipeline - Main pipeline orchestrator

Pipeline Steps:
1. Load Green + Yellow taxi data
2. Normalize schemas (unify column names)
3. Combine datasets
4. Add trip duration calculation
5. Clean data (remove invalid rows)
6. Compute aggregations:
   - Trips per day
   - Revenue per day
   - Peak hours per day
   - Daily average metrics
   - Anomaly detection (statistical analysis)
7. Save to CSV files (5 files)

Output Files:
- trips_per_day.csv         (~60 rows)
- revenue_per_day.csv       (~60 rows)
- peak_hour_per_day.csv     (~60 rows)
- daily_avg_metrics.csv     (~60 rows)
- anomaly_monitoring.csv    (~60 rows)

Run: python data_pipeline.py
